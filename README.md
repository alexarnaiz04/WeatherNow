# WeatherNow

WeatherNow is a medium-level Android application developed for the Mobile Application Development course.

## Description

The app is designed to show current weather information, forecast data, search history and favourite locations.

## Complexity level

Medium

## Technologies

- Kotlin
- Jetpack Compose
- Clean Architecture
- Room
- Retrofit
- Hilt
- Navigation Compose
- ViewModel
- Flow

## Build instructions

1. Open the project in Android Studio.
2. Sync Gradle.
3. Run the app using an emulator or Android device.

## Current status

This version contains the initial application skeleton for Project Class 3.
